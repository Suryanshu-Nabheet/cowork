# Security Policy

## Reporting vulnerabilities

Please report security issues and vulnerabilities responsibly by opening a security advisory or contacting **suryanshunab@gmail.com** or creating a private report via GitHub. Do not open public GitHub issues for sensitive security bugs.

Please include:
- Clear steps to reproduce the issue
- Potential impact and vulnerability severity
- Any proof of concept or mitigation suggestions

We will acknowledge your report promptly and work on a fix. Please do not publish details of unfixed vulnerabilities.

## Scope

This policy covers the CoWork self-hosted platform in **this repository** (`https://github.com/Suryanshu-Nabheet/cowork`).

Out of scope:
- Third-party AI model providers and external APIs
- External services (Composio, E2B, etc.)
- Operator misconfiguration (exposed environment secrets, open database ports, weak master secrets)

## Supported versions

Security fixes are prioritized on the `main` branch and tagged releases.
